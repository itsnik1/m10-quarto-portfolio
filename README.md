# M10 Quarto Portfolio

Four-page Quarto portfolio created for IBM 6500.

## Render in RStudio

Open `m10-quarto-portfolio.Rproj`, then click **Build Website** in the Build pane. The rendered files will be written to `_site`.

## Publish to GitHub Pages

After committing and pushing the project to GitHub, run this command from the RStudio Terminal:

```sh
quarto publish gh-pages
```

After the site is live, confirm the links in `_variables.yml`, render the project again, and submit `submission.qmd` and `submission.html`.
